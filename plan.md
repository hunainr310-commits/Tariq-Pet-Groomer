# Implementation plan — Tariq Pet Grooming

## Product scope
Recreate the Groomery Framer template as a close brand adaptation for Tariq Pet Grooming. This is a public, responsive grooming-business website, retaining the source's long-form landing-page story and visual hierarchy while using the confirmed Blueprint scope: reference-inspired homepage, service/pricing presentation, business/about story, groomer/team presentation, testimonials, FAQs, contact/appointment inquiry, matching navigation/footer, and responsive layouts with subtle motion. Do not claim unprovided business facts (address, years in operation, review count, accreditation, hours, phone, email, or real testimonials). Make unverified example pricing and testimonials visibly replaceable/for-confirmation. The inquiry form is a front-end demo until Tariq's email or booking destination is provided; it must not falsely claim an inquiry was delivered.

## Design direction
Follow the supplied Groomery reference rather than introducing a new design. **Design movement:** contemporary boutique pet-care editorial, with the reference's calm, local salon feel. **Core principles:** warm and reassuring; spacious magazine-like sections; photography leads the story; clear appointment paths. **Color philosophy:** warm off-white and oatmeal surfaces with dark ink and a restrained moss/forest accent, evoking a sunlit neighborhood studio. **Layout paradigm:** wide asymmetric editorial hero, alternating image/text sections, generous full-width breaks and compact service/review cards; avoid a generic centered SaaS layout. **Signature elements:** soft rounded image corners; small uppercase eyebrow labels; warm accent buttons and thin dividers. **Interaction philosophy:** navigation anchors and booking links scroll to the inquiry area, FAQ accordions open accessibly, and the contact form provides validation plus an explicit demo-only success note. **Animation:** brief, low-amplitude hover/fade transitions; honor reduced-motion preferences and do not delay content. **Typography:** expressive serif display headings paired with a clean sans-serif body; import fonts using the template's existing font setup or CSS font stacks. **Brand essence:** one-to-one, gentle grooming for pets and their people; calm, caring, thoughtful. **Brand voice:** warm, plainspoken, never boastful (e.g. “A gentler kind of groom.” / “Good care, at your pet’s pace.”). **Wordmark:** typographic “Tariq” with a simple paw/comb motif created in the UI, not generated type. **Signature color:** deep moss green.

## Implementation approach
Use the initialized React/Vite static website. Implement the landing page as semantic, accessible React sections and reusable arrays/components for services, process, reviews, FAQs, and team. The page flow should mirror the source: header/navigation and booking CTA; hero with headline, description, primary/secondary actions, image and understated trust line; services; calm-care/about feature; team card(s); four-step visit flow; studio gallery/stat strip; testimonials; fresh cuts gallery; FAQ; final CTA; and footer with business/contact placeholders. About, team, and contact remain sections on the primary page so the result keeps the template's single-page browsing feel. Make internal anchors usable on keyboard and mobile. Use a client-side-only inquiry form with required pet/owner/contact/service/message fields; explain on submit that this preview does not deliver inquiries until the owner's contact endpoint is connected. Do not introduce a database or server for this static marketing site.

Add original grooming/studio images only for identified placements: a wide hero portrait; one calm-care/about image; separate pet portraits for gallery/review cards; and an atmospheric studio image. Use the visual language observed in the reference, and avoid generated text in imagery. Keep all image URLs/paths project-managed and optimize through appropriate `object-fit` and responsive sizes. Ensure `public/manus-routes.json` declares the actual route set before starting the dev server, and set route title/description in the initial HTML. Keep styling scoped in the existing stylesheet and build for narrow mobile screens without horizontal overflow.

## Project structure
- `client/src/pages/Home.tsx`: page sections, content arrays, interactions, anchor structure.
- `client/src/index.css`: site palette, typography, responsive section layouts and reduced-motion rules.
- `client/index.html`: document metadata and loading entry.
- `client/public/` or the starter's public directory: route manifest, favicon/brand files, and static assets.
- `plan.md`, `TODO.md`: accepted plan and outcome tracking.

## Dependencies and serving
Use the already-installed React, Vite, Lucide and Framer Motion packages only where helpful; avoid unnecessary new dependencies. No business API, booking system, managed database, or server is configured. Run through the existing `pnpm dev:static` command on the configured port 3000 and use `pnpm build:static` for the static artifact.
